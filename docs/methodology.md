# Methodology

This research follows a Design Science Research (DSR) methodology.

## Phase 1

Literature Review

- AI-assisted programming
- LLM security
- Secure SDLC
- DevSecOps
- AI coding assistants

---

## Phase 2

Research Gap Analysis

Identify limitations of current Secure SDLC frameworks.

---

## Phase 3

Framework Design

Design a secure AI-assisted Software Development Lifecycle.

---

## Phase 4

Validation

Validate the framework using a practical software development case study.

---

## Phase 5

Evaluation

Compare the proposed framework with traditional Secure SDLC methodologies.
