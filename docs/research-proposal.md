# Research Proposal

## Working Title

Towards Secure LLM-Assisted Full Stack Software Development: Security Challenges, Risk Analysis, and an AI Secure Software Development Lifecycle Framework

## Research Question

How can organizations securely adopt LLM-assisted software development while minimizing security risks introduced by AI-generated code?

## Objectives

- Identify emerging AI coding risks
- Study existing Secure SDLC models
- Analyze AI-assisted development
- Design a new AI Secure SDLC
- Evaluate the framework

## Expected Contribution

A secure software development lifecycle specifically designed for AI-assisted software engineering.
