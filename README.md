## Working Title

**Towards Secure LLM-Assisted Full Stack Software Development: Security Challenges, Risk Analysis, and an AI Secure Software Development Lifecycle Framework**

---

## Overview

Large Language Models (LLMs) have transformed software engineering by assisting developers with code generation, debugging, testing, documentation, and architecture design. While these tools significantly improve productivity, they also introduce new security challenges that traditional Secure Software Development Lifecycle (Secure SDLC) models were not designed to address.

This research investigates the emerging security risks of AI-assisted software development and proposes a secure AI-aware software development lifecycle for enterprise applications.

---

## Objectives

- Study AI-assisted software engineering
- Analyze security risks introduced by LLMs
- Review existing Secure SDLC models
- Design an AI Secure SDLC Framework
- Validate the framework using practical case studies
